## 三、后端逻辑修改（改变页面内容）

### 3.1 热门排行改排序规则

文件：`app/routes/article.py`
```python
# 当前：按浏览量
hot_articles = Article.query...order_by(db.desc('view_count'))

# 改成：按点赞数
hot_articles = Article.query...order_by(db.desc('like_count'))

# 改成：近30天热门
from datetime import datetime, timedelta
thirty_days = datetime.now() - timedelta(days=30)
hot_articles = Article.query.filter(
    Article.is_published == True,
    Article.created_at >= thirty_days
).order_by(db.desc('view_count'))
```

### 3.2 标签云过滤空标签

文件：`app/routes/article.py`
```python
# 当前
tags = Tag.query.all()

# 改成：只显示有文章的标签
tags = [t for t in Tag.query.all() if t.article_count > 0]

# 或者：限制最多15个标签
tags = Tag.query.all()[:15]
```

### 3.3 文章排序 & 分页

文件：`app/routes/article.py`
```python
# 当前：按发布时间倒序
query = query.order_by(db.desc('created_at'))

# 改成：按点赞高优先
from sqlalchemy import func
query = query.outerjoin(Like).group_by(Article.id).order_by(
    func.count(Like.id).desc(), db.desc('created_at')
)

# 改成：每页4篇
result = paginate(query, page, per_page=4)
```

### 3.4 新增/删除分类

分类不是直接在页面文件修改，而是通过**后台管理界面**操作：

1. 用管理员账号登录（admin / 123456）
2. 顶部导航栏点击用户名 → **后台管理**
3. 进入「分类管理」→ 添加/编辑/删除
4. 左侧边栏分类列表会自动更新

## 四、常见自定义场景

### 场景1：想给文章卡片加封面图
在 `app/templates/article/index.html` 的 `<article class="article-card">` 最上面加：
```html
{% if article.cover_image %}
<div class="card-cover">
    <img src="{{ url_for('static', filename='upload/' + article.cover_image) }}" alt="">
</div>
{% endif %}
```
配套 CSS：
```css
.card-cover {
    width: 100%;
    height: 180px;
    overflow: hidden;
    border-radius: 8px 8px 0 0;
}
.card-cover img {
    width: 100%;
    height: 100%;
    object-fit: cover;
}
```

### 场景2：加「置顶」标识
在 `app/models.py` 的 Article 类加字段：
```python
is_pinned = db.Column(db.Boolean, default=False)
```
然后模板标题旁加：
```html
{% if article.is_pinned %}<span class="pinned-badge">📌 置顶</span>{% endif %}
```

### 场景3：搜索框中加 placeholder 提示
文件：`app/templates/article/index.html`
```html
<aside class="sidebar">
    <!-- 在任意位置插入搜索框 -->
    <section class="sidebar-section">
        <h3 class="section-title">🔍 搜索</h3>
        <div class="section-body">...</div>
    </section>
</aside>
```
